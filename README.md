# Paid Media ROAS & A/B Test Analyzer

Two calculators used in day-to-day paid media analysis: campaign efficiency (ROAS, CPC, CTR, CPM) and a proper z-test for creative A/B test significance.

## What it demonstrates

- ROAS/CPC/CTR/CPM as the primary efficiency metrics for budget allocation decisions
- A real two-proportion z-test for A/B significance (not just "B looks bigger than A")
- Practical marketing analytics that ties directly to paid media budget decisions

## Stack

Plain HTML/CSS/JS. No dependencies, no backend. Deploys as a static site.
